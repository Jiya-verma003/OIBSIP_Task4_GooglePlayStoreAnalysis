# Google Play Store Analysis

## Objective
This project analyzes the Google Play Store dataset using Python. It includes data cleaning, exploratory data analysis (EDA), revenue estimation, and sentiment analysis using VADER.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- VADER Sentiment Analysis
- Jupyter Notebook

## Dataset
Google Play Store Apps Dataset:
https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Features
- Data Cleaning
- Category Analysis
- Rating Analysis
- Size vs Installs Analysis
- Free vs Paid App Analysis
- Revenue Estimation
- Sentiment Analysis
- Interactive Plotly Visualization

## Conclusion
Most apps are free and highly rated. The FAMILY and GAME categories show high engagement, and most user reviews are Neutral or Positive.
